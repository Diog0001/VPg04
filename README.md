# RAG-помощник для Telegram

Умный бот, который отвечает на вопросы, ищет смысл в векторной базе [Pinecone](https://www.pinecone.io/), запоминает факты о пользователе, читает статьи по ссылке и умеет взять случайный факт из [Star Wars API](https://swapi.dev/).

Чат и эмбеддинги идут через OpenAI-совместимый API [ChadGPT](https://support.chadgpt.ru/?section=api&doc=text), а не напрямую в OpenAI.

---

## Что сделано

- Класс `RAGAgent` в `rag_agent.py` — ядро помощника без привязки к Telegram.
- Telegram-бот на [PyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) в `main.py`.
- Агентный RAG на LangGraph: модель сама решает, искать в базе, прочитать URL, сохранить заметку или вызвать внешний API.
- Хранение текстов как эмбеддингов в Pinecone.
- Эвристическая память о человеке: фразы вроде «меня зовут…», «я живу…», «запомни…» пишутся в базу отдельно от общих знаний.
- Чтение HTML-страниц: текст режется на чанки и уходит в Pinecone. Для [Дзена](https://dzen.ru/) добавлен обход пустой SSO-страницы Яндекса.
- Вместо заглушки API — GET к SWAPI: случайный персонаж, планета, корабль, фильм и т.д.
- История диалога в боте: короткие ответы «да», «ещё», «ок» относятся к прошлой реплике, а не запускают новый поиск.
- Кнопки по категориям вместо команд `/add` и `/remember`.
- Логи `[Pinecone]` и `[SWAPI]` в терминале при записи чанков и запросах к API.

## Как это устроено

```
Сообщение в Telegram
        ↓
   main.py (кнопки + история чата)
        ↓
   RAGAgent.ask()
        ↓
   ┌────────────┬──────────────┬─────────────────┐
   │ Pinecone   │ Чтение URL   │ GET swapi.dev   │
   │ поиск /    │ → чанки →    │ случайный факт  │
   │ запись     │   векторы    │ Star Wars       │
   └────────────┴──────────────┴─────────────────┘
        ↓
   Ответ моделью ChadGPT
```

Обычный текст — вопрос к помощнику. Перед ответом агент может поискать в базе. Кнопки вызывают конкретные действия без «угадывания» намерения.

## Кнопки бота

**Главное меню**

| Кнопка | Что делает |
|--------|------------|
| База знаний | Меню работы с общей векторной базой |
| Память | Факты именно о вас |
| Справка | Краткая инструкция |

**База знаний**

| Кнопка | Что делает |
|--------|------------|
| Поиск по базе | Семантический поиск, показывает фрагменты без генерации ответа |
| Добавить текст | Сохраняет заметку в Pinecone |
| Добавить статью по URL | Скачивает страницу, делит на чанки, пишет векторы |
| Назад | В главное меню |

**Память**

| Кнопка | Что делает |
|--------|------------|
| Запомнить обо мне | Явно сохранить факт о вас |
| Назад | В главное меню |

`/start` нужен, чтобы открыть бота и показать клавиатуру. Он же сбрасывает историю диалога.

## Быстрый старт

### 1. Окружение

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell ругается на скрипт активации:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2. Ключи

Скопируйте `.env.example` в `.env` и заполните:

```
OPENAI_API_KEY=          # ключ ChadGPT, кабинет → «Управление API»
OPENAI_BASE_URL=https://ask.chadgpt.ru/api/v1
OPENAI_CHAT_MODEL=gpt-5-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small

PINECONE_API_KEY=
PINECONE_INDEX_NAME=rag-agent
PINECONE_CLOUD=aws
PINECONE_REGION=us-east-1

TELEGRAM_BOT_TOKEN=      # токен от @BotFather
```

Имена `OPENAI_*` оставлены специально: так подключается OpenAI-совместимый клиент ChadGPT.

Индекс Pinecone создаётся сам при первом запуске, если его ещё нет. Размерность для `text-embedding-3-small` — 1536.

### 3. Запуск бота

```powershell
python main.py
```

В терминале должны появиться строки вроде:

```
Подключаю RAG-агент…
[Pinecone] Подключился к существующему индексу «rag-agent».
Бот запущен. Нажмите Ctrl+C для остановки.
```

Напишите боту `/start`.

Проверка только Pinecone без Telegram:

```powershell
python rag_agent.py
```

## Как пользоваться

1. Задайте вопрос обычным сообщением — бот может поискать в базе и ответить.
2. «Меня зовут Иван, я живу в Казани» — факт сохранится в персональную память.
3. **База знаний → Добавить статью по URL** — вставьте ссылку на статью.
4. **База знаний → Поиск по базе** — найдите фрагменты по смыслу.
5. «Расскажи случайный факт из Star Wars» — GET к [swapi.dev](https://swapi.dev/). На «да» или «ещё» придёт следующий факт, а не новый поиск по базе.
6. Смотрите терминал: там видно, сколько чанков записано и какой запрос ушёл в SWAPI.

## Tools агента

Модель может вызывать:

- `retrieve_knowledge` — поиск в Pinecone (общие знания + память пользователя);
- `ingest_web_page` — прочитать URL и сохранить чанки;
- `add_knowledge` — добавить текст в общую базу;
- `save_user_fact` — сохранить факт о человеке;
- `get_starwars_fact` — случайный факт через GET `https://swapi.dev/api/`.

## Если что-то пошло не так

- **Нет текста на странице Дзена.** Раньше сайт отдавал пустую SSO-страницу. В текущей версии текст статьи достаётся после автологина. Перезапустите бота после обновления кода.
- **В терминале пусто при сохранении.** Логи есть только в новой версии процесса. Остановите бота Ctrl+C и запустите `python main.py` снова.
- **Эмбеддинги 400: Input should be a valid string.** ChadGPT ждёт строку, а не токены. В коде уже стоит `check_embedding_ctx_length=False`.
- **Бот не видит кнопки.** Нажмите `/start`.
- **«да» уводит в чужие статьи.** Нужна версия с историей диалога; после `/start` история начинается заново.
